## Hey, I'm Max 🦒

I like building things that make sound, move electrons, or both.

AI assistants have widened what a single developer can build, so I write more and more **Rust**:
CLIs, audio and embedded code. I still build for the **web** too.

When I'm not coding I'm making **house music**, which is probably why so much of my code ends up
being about audio.

### What I'm into
- 🦀 **Rust**: CLIs, libraries, audio and embedded
- 🔊 **Linux audio**: low-latency pipelines, getting sound out of small boards, I²S/TDM audio chips
- 🔌 **Electronics & embedded**: STM32 and Atmel microcontrollers, bootloaders, talking to hardware
  over USB
- 🐧 **Embedded Linux**: building minimal systems from scratch with Buildroot
- 🔒 **Security**: an eye for code injection and for treating every outside input as possibly
  malicious data
- 🌐 **Web**: backends, tooling, the occasional frontend
- 🎧 **House music**: [soundcloud.com/max-matteo](https://soundcloud.com/max-matteo)

### Recent projects
- [**kingst-la1010-control**](https://github.com/mstaack/kingst-la1010-control): use a Kingst LA1010
  USB logic analyzer from the terminal instead of the vendor GUI. Clip it onto a board and it measures
  clock frequencies and duty cycles, records captures you can open in PulseView, and decodes UART, I²C,
  SPI and USB 1.x traffic live, as readable text or JSON for scripts and AI agents.
- [**isdt-mp305-control**](https://github.com/mstaack/isdt-mp305-control): drive my ISDT MP305 bench
  power supply from the command line. Set voltage and current limits, switch the output, watch live
  readings, log them to CSV for long tests, and charge batteries. One static binary, no drivers.
- [**lc-menubar**](https://github.com/mstaack/lc-menubar): Laravel Cloud in the macOS menu bar. A status
  dot shows failed or running deployments at a glance; the menu has every environment with CPU, memory
  and request charts, spend per organization, and quick actions like deploy, logs and env vars.
